# שכונה 360° · שער היעדים

**[shchuna-360.vercel.app](https://shchuna-360.vercel.app)** · הכתובת החיה
קישור למיזוג האחרון, בלי Vercel: [raw.githack](https://raw.githack.com/Anat1969/pro-metrics-vue-GH/main/app/index.html) (בפעם הראשונה: "Open the page").

**האם תוכנית ההתחדשות עומדת ביעד, לפני שמאשרים?** של **עיריית אשדוד** (Ashdod Municipality).
כל תוכנית התחדשות עירונית בעיר נבדקת מול היעד של שלב האישור שלה: אישור תב"ע או אישור תוכנית בינוי. התשובה: עומדת, תלויה בראיות, או לא עומדת, ומה לדרוש מהיזם.

**האפליקציה האחות, [מכשיר המדידה](https://shchuna360.vercel.app)** (`Shchuna360-GH`), עונה על שאלה אחרת: כמה התוכנית שווה. היא מנקדת כל מדד מתוך מסמכי התוכנית. מכאן רק קוראים את המדידות שלה.

## מה יש בו
- **לוח התוכניות בעיר:** 18 תוכניות, בשורה לכל שער, מול היעד. יעד לכל שער, וסינון לפי שער ומצב.
- **החלטה לכל תוכנית:** כמה אפשר לדרוש בשלב (תב"ע עד 94, תוכנית בינוי 120), מה הוכח, מה חסר בתוך השלב, מה עתידי, ותנאי היתר וביצוע.
- **בדיקות אוטומטיות** עם הסבר איך כל אחת נבדקה, **בקשת מסמכים** מאוחדת מהיזם, ו**דוח מלא** להדפסה ול-Word.
- **דף בית:** העיר בתלת־ממד (הטלה איזומטרית ב-SVG). מבנה לכל תוכנית, וזכוכית צהובה בגובה היעד.
- **בדיקה ידנית** לתוכנית שעוד לא במערכת, במסך אחד: רשימה ומסננים, שושנת 360°, ועריכת המדד בטור צד. שמירה אוטומטית.
- **הערכה אוטומטית שמסבירה את עצמה:** מה חושב בקוד, מה קבע איש המקצוע, והמגבלה.
- **הזדמנויות:** המדדים עם הכי הרבה נקודות פתוחות.
- **יומן שינויים** ו**דוח Word** לצירוף לתיק התכנון.
- התקנה מ-Chrome, נייד, RTL, הפחתת תנועה.

## מבנה
- `src/data/indicators.ts`: מקור הנתונים היחיד (מדדים, פרקים, צבעים).
- `src/lib/scoring.ts`: חישוב, הזדמנויות, חיפוש בעברית.
- `src/lib/rose.ts`: גאומטריית השושנה (רוחב לפי משקל, שטח לפי ציון).
- `src/components/Rose.tsx`, `IsoRose.tsx`: השושנה והתלת־ממד.
- `src/pages/HomeView.tsx`, `DashboardView.tsx`: שני הדפים. המצב נשמר בכתובת (`?i=`, `?ch=`, `?t=`, `?v=log`).
- הנתונים נשמרים ב-localStorage (`shchuna360_projects`), בדפדפן שבו נוצרו.
